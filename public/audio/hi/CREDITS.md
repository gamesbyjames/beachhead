# Hindi pronunciation

Phrase text, romanization, English glosses, and the existing spoken MP3 files are imported from the user's repository:

https://github.com/gamesbyjames/lingo_run

The source project identifies these as ElevenLabs-generated Hindi speech. No new speech is generated by Beachhead. The exact source revision and original phrase IDs are recorded in `public/lessons/hi-course.json`, which contains all eight topics and 44 phrases.

Refresh the complete course with `node tools/import-hindi.mjs`.
